# 02 — Design system and application layout

## Objective

Build responsive shell and reusable accessible components.

## Prerequisites and dependencies

01; branding supplied or open issue recorded.

## Actionable tasks

- [ ] Define visual tokens.
- [ ] Build header/navigation/content shell and sign-out affordance.
- [ ] Make nav keyboard/mobile usable.
- [ ] Add buttons, inputs, cards, badges, loading/empty/error states and confirmation.
- [ ] Add landmarks, focus visibility, contrast, reduced motion; check narrow/wide layouts.

Responsive shell and reusable UI states.

Keyboard usable, consistent, readable and no narrow-screen overflow.

## Relevant API endpoints and database tables

None.

## Assumptions and follow-up decisions

No Figma inspection; use available assets and apply supplied brand later.
